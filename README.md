# 세무사 1차 핵심개념 — 홈 화면 앱 설치

## 1. GitHub에 올리기 (5분, 코딩 필요 없음)
1. github.com 가입 후 오른쪽 위 **+ → New repository**
2. Repository name: `semusa` / **Public** 선택 / Create repository
3. **uploading an existing file** 클릭 → 이 폴더의 파일 5개(index.html, manifest.json, sw.js, icon-192.png, icon-512.png)를 끌어다 놓고 **Commit changes**
4. 저장소 **Settings → Pages → Branch: main → Save**
5. 1~2분 후 같은 화면에 주소가 뜹니다: `https://아이디.github.io/semusa/`

## 2. 안드로이드 폰에 설치
1. Chrome에서 위 주소 열기
2. 오른쪽 위 ⋮ 메뉴 → **홈 화면에 추가** (또는 "앱 설치")
3. 홈 화면 아이콘으로 열면 전체화면 앱처럼 동작, 지하철에서도 카드·테스트 가능

## 3. (선택) 단어 설명·질문 기능 켜기
1. console.anthropic.com 가입 → API Keys → Create Key
2. 앱 오른쪽 위 **설정 · API 키** → 키 붙여넣기 → 저장
- 키가 없어도 카드·테스트·오늘의 학습지는 전부 됩니다.

## 진도
- 폰에 자동 저장됩니다. 폰을 바꿀 때는 설정 → 진도 백업 코드로 옮기세요.
- Claude 앱 안의 버전과 진도를 맞추려면 백업 코드를 서로 붙여넣으면 됩니다.

## 매일 알림
- 폰 기본 시계 앱에서 매일 알람을 하나 만들어 "세무사 학습지"로 이름 붙이는 게 가장 확실합니다.
